Non-homogeneous case

Let’s now consider the non-homogeneous diffusion equation with a constant decay rate \(\beta\) and point-like sources that constantly inject material into the system:

\[ \frac{\partial v}{\partial t} = D \nabla^2 v + Q(x,y,t) - \beta v \tag{1}\]

where \[ Q(x,y,t) = \sum_{i=1}^N A_i(t) \delta(x-x_i) \delta(y-y_i) \] represents point-like sources located at positions \((x_i,y_i)\) with time-dependent injection rates \(A_i(t) > 0\), and \(v(x,y,t)\) is the new function we want to solve for.

As before, we will assume reflective boundary conditions on all sides of the rectangular domain of size \(L_x \times L_y\)

NoteBiological interpretation of the non-homogeneous diffusion equation

In the context of bacterial cell-cell signaling, the non-homogeneous diffusion equation with point-like sources can be used to model the concentration of a diffusible signaling molecule (e.g. a quorum sensing autoinducer) in a 2D environment where \(N\) bacteria are located at specific positions \((x_i,y_i)\) and secrete the molecule at rates \(A_i(t)\) that can vary over time (e.g. due to changes in gene expression or environmental conditions). The decay term \(\beta v\) can represent the degradation of the signaling molecule in the environment, which can occur due to enzymatic activity, chemical instability, or uptake by cells.

NoteChallenges in solving the non-homogeneous diffusion equation

If we try to use separation of variables as before, we find that the presence of the non-homogeneous term makes it impossible to separate the variables: \[ \frac{1}{T(t)} \frac{dT}{dt} = D \left( \frac{1}{X(x)} \frac{d^2 X}{dx^2} + \frac{1}{Y(y)} \frac{d^2 Y}{dy^2} \right) + \underbrace{\frac{Q(x,y,t)}{X(x) Y(y) T(t)}}_{ \text{non-separable term}} - \beta \]

The presence of the non-separable term \(\frac{Q(x,y,t)}{X(x) Y(y) T(t)}\), which depends on all three variables \(x\), \(y\), and \(t\), prevents us from separating the variables.

Solution using eigenfunction expansion

We will start by assuming that the solution \(v(x,y,t)\) can be written as a sum of eigenmodes, similar to what we did in Equation 2.10 in Infinite sum of eigenmodes for the homogeneous case:

\[ v(x,y,t) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} T_{n,m}(t) \Phi_{n,m}(x,y) \tag{2}\]

where \(T_{n,m}(t)\) are time-dependent coefficients to be determined and \(\Phi_{n,m}(x,y)\) are the eigenfunctions of the Laplacian operator with Neumann boundary conditions (Equation 2.1).

We also express the source term \(Q(x,y,t)\) as a linear combination of the same eigenfunctions \(\Phi_{n,m}(x,y)\):

\[ Q(x,y,t)= \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} q_{n,m}(t) \Phi_{n,m}(x,y) \tag{3}\]

where \(q_{n,m}(t)\) are the coefficients of the source term expansion, which can be determined by projecting \(Q(x,y,t)\) onto the eigenfunctions \(\Phi_{n,m}(x,y)\), as we will see later.

where \(q_{n,m}(t)\) are the coefficients of the source term expansion. To find these coefficients, we can use a similar procedure as the one described in Determining the amplitudes of the eigenmodes. But this time, instead of projecting the initial condition onto the eigenfunctions, we will project the time-dependent source term \(Q(x,y,t)\) onto the eigenfunctions:

This leads us to the following expression for \(q_{n,m}(t)\):

\[ q_{n,m}(t) = \frac{4 \varepsilon_n \varepsilon_m}{L_x L_y} \sum_{i=1}^N A_i(t) \Phi_{n,m}(x_i,y_i) \tag{4}\]

Now we can substitute the expansion for \(v(x,y,t)\) and \(Q(x,y,t)\) into the original PDE Equation 1.

NoteDerivation of ODEs for eigenmode coefficients

Since the equation is large, we will represent the infinite sum of infinite eigenmodes as \(\sum_{n,m}^{\infty, \infty}\) for brevity:

\[ \frac{\partial}{\partial t} \left( \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \Phi_{n,m}(x,y) \right) = D \nabla^2 \left( \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \Phi_{n,m}(x,y) \right) + \] \[ \sum_{n,m}^{\infty, \infty} q_{n,m}(t) \Phi_{n,m}(x,y) - \beta \left( \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \Phi_{n,m}(x,y) \right) \] Rearranging the terms gives:

\[ \sum_{n,m}^{\infty, \infty} \frac{d T_{n,m}(t)}{dt} \Phi_{n,m}(x,y) = D \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \nabla^2 \Phi_{n,m}(x,y) + \] \[ \sum_{n,m}^{\infty, \infty} q_{n,m}(t) \Phi_{n,m}(x,y) - \beta \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \Phi_{n,m}(x,y) \]

As shown in Eigenvalue equation verification, we know that the eigenfunctions \(\Phi_{n,m}(x,y)\) satisfy the eigenvalue equation shown in Equation 2.4. Which allows us to replace \(\nabla^2 \Phi_{n,m}(x,y)\) with \(-\lambda_{n,m} \Phi_{n,m}(x,y)\):

\[ \sum_{n,m}^{\infty, \infty} \frac{d T_{n,m}(t)}{dt} \Phi_{n,m}(x,y) = -D \sum_{n,m}^{\infty, \infty} \lambda_{n,m} T_{n,m}(t) \Phi_{n,m}(x,y) + \] \[ \sum_{n,m}^{\infty, \infty} q_{n,m}(t) \Phi_{n,m}(x,y) - \beta \sum_{n,m}^{\infty, \infty} T_{n,m}(t) \Phi_{n,m}(x,y) \]

We can now group by the eigenfunctions \(\Phi_{n,m}(x,y)\):

\[ \sum_{n,m}^{\infty, \infty} \left( \frac{d T_{n,m}(t)}{dt} + (D \lambda_{n,m} + \beta) T_{n,m}(t) - q_{n,m}(t) \right) \Phi_{n,m}(x,y) = 0 \]

A linear combination of linearly independent eigenfunctions \(\Phi_{n,m}(x,y)\) can only be equal to zero if the coefficient of each eigenfunction is equal to zero.

This leaves us with an ordinary differential equation for each mode \((n,m)\):

\[ \frac{d T_{n,m}(t)}{dt} + (D \lambda_{n,m} + \beta) T_{n,m}(t) = q_{n,m}(t) \tag{5}\]

This is a first-order linear ODE, which we have to solve for each pair \((n,m)\)

NoteSolving the ODEs for eigenmode coefficients

For solving this, we can use the integrating Factor method, where we will use \(e^{k_{n,m} t}\) as the integrating factor, where \(k_{n,m} = D \lambda_{n,m} + \beta\).

Multiplying both sides of equation Equation 5 by the integrating factor gives:

\[ e^{k_{n,m} t} \frac{d T_{n,m}(t)}{dt} + k_{n,m} e^{k_{n,m} t} T_{n,m}(t) = q_{n,m}(t) e^{k_{n,m} t} \]

The left-hand side can be recognized as the derivative of the product \(e^{k_{n,m} t} T_{n,m}(t)\):

\[ \frac{d}{dt} \left( e^{k_{n,m} t} T_{n,m}(t) \right) = q_{n,m}(t) e^{k_{n,m} t} \]

Integrating both sides with respect to \(t\) from \(0\) to \(t\) gives:

\[ \left[ e^{k_{n,m} t} T_{n,m}(t) \right]_0^t = \int_0^t q_{n,m}(\tau) e^{k_{n,m} \tau} d\tau \] This simplifies to: \[ e^{k_{n,m} t} T_{n,m}(t) - T_{n,m}(0) = \int_0^t q_{n,m}(\tau) e^{k_{n,m} \tau} d\tau \]

Solving for \(T_{n,m}(t)\) gives:

\[ T_{n,m}(t) = e^{-k_{n,m} t} T_{n,m}(0) + \int_0^t q_{n,m}(\tau) e^{-k_{n,m} (t-\tau)} d\tau \]

We need to determine \(T_{n,m}(0)\) using the initial condition for \(v(x,y,0)\):

\[ v(x,y,0) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} T_{n,m}(0) \Phi_{n,m}(x,y) \]

Using the orthogonality property of the eigenfunctions shown in Infinite sum of eigenmodes, we can find \(T_{n,m}(0)\) as:

\[ T_{n,m}(0) = \frac{4 \varepsilon_n \varepsilon_m}{L_x L_y} \int_0^{L_x} \int_0^{L_y} v(x,y,0) \Phi_{n,m}(x,y) dy dx \tag{6}\]

Final solution

Substituting \(T_{n,m}(t)\) back into the eigenfunction expansion for \(v(x,y,t)\) in equation Equation 1.2, we obtain the final solution for the non-homogeneous diffusion equation with point-like sources:

\[ v(x,y,t) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} \left[ e^{-k_{n,m} t} T_{n,m}(0) + \int_0^t q_{n,m}(\tau) e^{-k_{n,m} (t-\tau)} d\tau \right] \phi_{n,m}(x,y) \] where

\[ k_{n,m} = D \lambda_{n,m} + \beta \] \[ \lambda_{n,m} = \left( \frac{n \pi}{L_x} \right)^2 + \left( \frac{m \pi}{L_y} \right)^2 \] \[ q_{n,m}(t) = \frac{4 \varepsilon_n \varepsilon_m}{L_x L_y} \sum_{i=1}^N A_i(t) \phi_{n,m}(x_i,y_i) \] \[ T_{n,m}(0) = \frac{4 \varepsilon_n \varepsilon_m}{L_x L_y} \int_0^{L_x} \int_0^{L_y} v(x,y,0) \phi_{n,m}(x,y) dy dx \]

Steady-state solution

Let’s now evaluate the shape of the solution as \(t \to \infty\), which should correspond to the steady-state solution in which \(\frac{\partial v}{\partial t} = 0\), assuming that the source terms \(A_i\) are constant in time.

As \(t \to \infty\), the exponential decay term \(e^{-k_{n,m} t}\) approaches zero for all modes \((n,m)\):

\[ \lim_{t \to \infty} e^{-k_{n,m} t} = 0 \]

Thus, the steady-state solution simplifies to:

\[ v_{ss}(x,y) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} \left[ q_{n,m} \int_0^{t} e^{-k_{n,m} (t-\tau)} d\tau \right] \phi_{n,m}(x,y) \] Now let’s solve the integral:

\[ \int_0^{t} e^{-k_{n,m} (t-\tau)} d\tau \] We can substitute \(u = t - \tau\), which gives \(d\tau = -du\). The limits of integration change accordingly: When \(\tau = 0\), \(u = t\); and when \(\tau = t\), \(u = 0\). Therefore, the integral becomes:

\[ \int_t^{0} e^{-k_{n,m} u} (-du) = \int_0^{t} e^{-k_{n,m} u} du = \left[ -\frac{1}{k_{n,m}} e^{-k_{n,m} u} \right]_0^{t} = \frac{1}{k_{n,m}} \left( 1 - e^{-k_{n,m} t} \right) \]

Taking the limit as \(t \to \infty\), we find:

\[ \lim_{t \to \infty} \int_0^{t} e^{-k_{n,m} (t-\tau)} d\tau = \frac{1}{k_{n,m}} \]

Thus, the steady-state solution becomes:

\[ \boxed{ v_{ss}(x,y) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} \frac{q_{n,m}}{k_{n,m}} \phi_{n,m}(x,y) } \]

where \[ k_{n,m} = D \lambda_{n,m} + \beta \] \[ \lambda_{n,m} = \left( \frac{n \pi}{L_x} \right)^2 + \left( \frac{m \pi}{L_y} \right)^2 \] \[ q_{n,m} = \frac{4 \varepsilon_n \varepsilon_m}{L_x L_y} \sum_{i=1}^N A_i \phi_{n,m}(x_i,y_i) \] \[ \phi_{n,m} = \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \]

We can confirm that this is the steady-state solution if we derive the solution directly from the steady-state version of the original PDE Equation 1, in which we set \(\frac{\partial v}{\partial t} = 0\):

\[ 0 = D \nabla^2 v_{ss} + Q(x,y) - \beta v_{ss} \] Rearranging gives:

\[ D \nabla^2 v_{ss} - \beta v_{ss} = - Q(x,y) \]

This is known as the inhomogeneous Helmholtz equation (also called the screened Poisson equation).

Plotting the steady-state solution

Let’s plot the steady-state solution for randomly placed point-like sources in a 2D domain.

Code 
Plotly = require("plotly.js-dist@2")

// Domain and parameters
Lx = 1
Ly = 1
D = 1
beta = 0.1
TruncationNmax = 25
TruncationMmax = 25

// Controls
N = 3

viewof resample_sources = Inputs.button("Resample sources", {
  value: 3,
  reduce: (count) => count 
})




// Grid resolution for plotting
Nx = 50
Ny = 50

// Random sources (recomputed when button is clicked)
producers = {
  resample_sources
  const arr = []
  for (let k = 0; k < N; k++) {
    const xk = Math.random() * Lx
    const yk = Math.random() * Ly
    arr.push([xk, yk])
  }
  return arr
}

A = Array.from({length: N}, () => 1.0)

// Helper: epsilon_n
function epsilon(n) {
  return n === 0 ? 0.5 : 1.0
}

// Helper: eigenfunction phi_{n,m}(x,y)
function phi(n, m, x, y) {
  return Math.cos(n * Math.PI * x / Lx) * Math.cos(m * Math.PI * y / Ly)
}

// Helper: eigenvalue lambda_{n,m}
function lambda(n, m) {
  return Math.pow(n * Math.PI / Lx, 2) + Math.pow(m * Math.PI / Ly, 2)
}

// Helper: k_{n,m} = D * lambda_{n,m} + beta
function k_nm(n, m) {
  return D * lambda(n, m) + beta
}

// Compute q_{n,m} for all modes
function compute_q_nm(n, m) {
  let sum = 0
  for (let i = 0; i < N; i++) {
    const xi = producers[i][0]
    const yi = producers[i][1]
    sum += A[i] * phi(n, m, xi, yi)
  }
  return (4 * epsilon(n) * epsilon(m) / (Lx * Ly)) * sum
}

// Create spatial grid
xGrid = Array.from({length: Nx}, (_, i) => i * Lx / (Nx - 1))
yGrid = Array.from({length: Ny}, (_, j) => j * Ly / (Ny - 1))

// Compute steady-state solution v_ss(x,y)
vss = {
  const z = []
  
  for (let j = 0; j < Ny; j++) {
    const row = []
    for (let i = 0; i < Nx; i++) {
      const x = xGrid[i]
      const y = yGrid[j]
      
      let value = 0
      // Sum over modes
      for (let n = 0; n <= TruncationNmax; n++) {
        for (let m = 0; m <= TruncationMmax; m++) {
          const q_nm = compute_q_nm(n, m)
          const k = k_nm(n, m)
          const phi_nm = phi(n, m, x, y)
          value += (q_nm / k) * phi_nm
        }
      }
      row.push(value)
    }
    z.push(row)
  }
  
  return z
}



mutable plotDivSolution = {
  const div = document.createElement("div")
  div.style.height = "700px"
  div.style.width = "90%"
  return div
}


solutionPlotEigen = {
  Plotly.react(plotDivSolution, [{
    type: 'surface',
    x: xGrid,
    y: yGrid,
    z: vss,
    colorscale: 'Viridis',
    contours: {
      z: {
    show: true,
    usecolormap: true,
    highlightcolor: "#42f462",
    project: { z: true },
    
      }
    },
    showscale: false
  }], {
    scene: {
      xaxis: { title: 'x' },
      yaxis: { title: 'y' },
      zaxis: { title: 'v_ss(x,y)' },
      aspectmode: 'cube'
    },
    width: 700,
    height: 700,
    margin: {
      l: 0,
      r: 0,
      b: 0,
      t: 30
    }
  })
  
}
