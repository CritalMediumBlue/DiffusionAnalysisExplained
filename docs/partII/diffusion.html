Analytical solution of the 2D diffusion

Let’s find the analytical solution to the following diffusion equation:

\[ \frac{\partial u}{\partial t} = D \nabla^2 u \tag{1}\]

The equation is defined on an two dimensional domain \(\Omega = [0,L_x] \times [0,L_y]\) (for example, a microfluidic chamber of size \(L_x\) by \(L_y\)) with reflective boundary conditions.

The initial and boundary conditions

The initial condition \(u(x,y,t=0)\) is given by a set of \(N\) instantaneous point sources located at positions \(\{(x_i,y_i)\}_{i=1}^N\) with strengths \(\{S_i\}_{i=1}^N\): \[ u(x,y,0) = \sum_{i=1}^N S_i \delta(x-x_i) \delta(y-y_i) \tag{2}\]

\(\delta\) is the Dirac’s delta function.

NoteSome details about the Dirac delta function

Dirac’s delta function is zero everywhere, except at the point where its argument is zero, where it is infinite:

\[ \delta(x) = \begin{cases} \infty & \text{if } x = 0 \\ 0 & \text{if } x \neq 0 \end{cases} \] This function has the property that its integral over the entire real line is equal to 1: \[ \int_{-\infty}^{\infty} \delta(x) dx = 1 \]

If we were to plot the initial condition \(u(x,y,0)\), we would see a flat surface with \(N\) vertical spikes at the positions of the point sources, where the height of each spike is infinitely tall but contains a finite total mass equal to \(S_i\) (total amount of substance released by the source \(i\)). For \(N=4\) randomly located sources, the plot would look like this:

If imagining the initial condition as a finite set of infinitely tall spikes is not very intuitive, we can also think of the initial condition as a finite sum of infinitely narrow Gaussian functions centered at the positions of the point sources.

NoteImagine the Dirac delta functions as narrow Gaussian functions

One way to look at the the initial condition is to approximate the Dirac delta functions by narrow Gaussian functions. If aproximated by narrow Gaussian functions, the initial condition becomes:

\[ u(x,y,0) = \lim_{\sigma \to 0} \ \sum_{i=1}^N S_i \frac{1}{2 \pi \sigma^2} \exp\left(-\frac{(x-x_i)^2 + (y-y_i)^2}{2 \sigma^2}\right) \tag{3}\]

For a small but non-zero value of \(\sigma = 0.03\), the plot of the initial condition would look like this:

Code

The Neumann boundary conditions are given by: \[ \frac{\partial u}{\partial x}\Big|_{x=0} = \frac{\partial u}{\partial x}\Big|_{x=L_x} = \frac{\partial u}{\partial y}\Big|_{y=0} = \frac{\partial u}{\partial y}\Big|_{y=L_y} = 0 \tag{4}\]

The following sections are dedicated to finding the solution step by step, starting with the method of separation of variables. If interested in the final solution, you can jump to section Final solution.

NoteBiological interpretation of the initial condition and boundary conditions

A biological interpretation of this initial condition could be the instantaneous release of a chemical substance by \(N\) bacterial cells located at positions \(\{(x_i,y_i)\}_{i=1}^N\) in a microfluidic chamber. In this case, the strength \(S_i\) of each point source would represent the total amount of substance released by the bacterial cell \(i\) at the initial time \(t=0\). The boundary conditions in Equation 4 would represent the fact that the walls of the microfluidic chamber are impermeable, so there is no flux of the chemical substance across the boundaries of the chamber. This means that the total amount of substance in the chamber remains constant over time, and the substance can only spread within the chamber through diffusion, but cannot escape or enter through the walls:

\[ \int_\Omega u(x,y,t) dx dy = \sum_{i=1}^N S_i \quad \text{for all } t \geq 0 \]

Method of separation of variables

For implementing the method of separation of variables, we will assume that the solution can be written as a product of three functions, each depending on only one of the variables:

\[ u(x,y,t) = X(x) Y(y) T(t) \tag{1.1}\]

NoteFrom PDE to ODEs using separation of variables

Substituting equation Equation 1.1 into equation Equation 1, we have:

\[ X Y \frac{dT}{dt} = D \left( Y T \frac{d^2X}{dx^2} + X T \frac{d^2Y}{dy^2} \right) \]

and dividing both sides by \(D X Y T\) gives: \[ \frac{1}{DT} \frac{dT}{dt} = \frac{1}{X} \frac{d^2X}{dx^2} + \frac{1}{Y} \frac{d^2Y}{dy^2} \tag{1.2}\] The left side of equation Equation 1.2 depends only on time \(t\), while the right side depends only on the spatial variables \(x\) and \(y\). So, the left-hand side and the right-hand side are completely independent of each other. The only way for two independent functions to be equal to each other for all values of \(x\), \(y\), and \(t\) is if they are both equal to the same constant. Therefore, we will denote this constant as \(-\lambda\). So, the left-hand side is equal to:

\[ \frac{1}{DT} \frac{dT}{dt} = -\lambda \]

and the right-hand side is equal to:

\[ \frac{1}{X} \frac{d^2X}{dx^2} + \frac{1}{Y} \frac{d^2Y}{dy^2} = -\lambda \]

This leads to three ordinary differential equations: \[ \frac{dT}{dt} + D \lambda T = 0 \tag{1.3}\] \[ \frac{d^2X}{dx^2} + \lambda_x X = 0 \tag{1.4}\] \[ \frac{d^2Y}{dy^2} + \lambda_y Y = 0 \tag{1.5}\] where \(\lambda = \lambda_x + \lambda_y\).

Now we can solve each of these equations separately.

Solving \(T(t)\)

The solution to equation Equation 1.3 is:

\[ T(t) = C_t e^{-D \lambda t} \tag{1.6}\]

NoteIntuition about the solution for T(t)

This is an exponential function, whose decaying rate is determined by the constant \(\lambda\). For a constant \(C_t = 1\), the plot of \(T(t)\) for different values of \(\lambda\) is shown below:

Solving \(X(x)\) and \(Y(y)\)

Now let’s focus on finding the solution to equation Equation 1.4 and equation Equation 1.5.

NoteSolving the equation for X(x)

We want to find functions that, when doubly differentiated with respect to \(x\) , return the same function multiplied by a constant:

\[ \frac{d^2X}{dx^2} = -\lambda_x X \]

NoteThis is an eigenvalue problem

We know that the double derivatives of exponential functions are proportional to the exponential function. So, let’s assume that the solution is an exponential function of the form \(X(x) = e^{kx}\), where \(k\) is an unknown constant. This way, if you take the second derivative of \(X(x)\), you will get:

\[ \frac{d^2X}{dx^2} = k^2 e^{kx} \tag{1.7}\]

which would satisfy equation Equation 1.4 if \(k^2 = -\lambda_x\).

Additionally, since Equation 1.4 is a linear second-order ordinary differential equation, we also know that all its solutions can be expressed as a linear combination of two linearly independent solutions. These two independent solutions form a basis for the solution space:

\[ X(x) = C_1 X_1(x) + C_2 X_2(x) \]

This leads us to a general solution of the form:

\[ X(x) = C_1 e^{k_1 x} + C_2 e^{k_2 x} \tag{1.8}\]

where \(k_1\) and \(k_2\) are unknown constants.

Now we can solve for \(k_1\) and \(k_2\) depending on the sign of \(\lambda_x\):

NoteEvaluating different cases for λx

Positive \(\lambda_x\)

NoteEvaluating the case of positive λx

If \(\lambda_x > 0\), then \(k_1 = i\sqrt{\lambda_x}\) and \(k_2 = -i\sqrt{\lambda_x}\).

This means that the 2 independent solutions are:

\[ X_1(x) = e^{i\sqrt{\lambda_x} x} \qquad \text{and} \qquad X_2(x) = e^{-i\sqrt{\lambda_x} x} \]

Thus, the general solution is: \[ X(x) = C_1 e^{i\sqrt{\lambda_x} x} + C_2 e^{-i\sqrt{\lambda_x} x} \] Using Euler’s formula \(e^{i\theta} = \cos(\theta) + i\sin(\theta)\), we can rewrite this as: \[ X(x) = A \cos(\sqrt{\lambda_x} x) + B \sin(\sqrt{\lambda_x} x) \tag{1.9}\] Let’s now consider the boundary conditions shown in equation Equation 4.

\[ \frac{\partial u}{\partial x}\Big|_{x=0} = 0 \implies \frac{dX}{dx}\Big|_{x=0} Y(y) T(t) = 0 \implies \frac{dX}{dx}\Big|_{x=0} = 0 \] This is because \(Y(y)\) and \(T(t)\) are not zero for all \(y\) and \(t\). If either of them were zero, then \(u(x,y,t)\) would be zero for all \(x\), which is not the case.

Calculating the derivative of Equation 1.9 gives:

\[ \frac{dX}{dx} = - A \sqrt{\lambda_x} \sin(\sqrt{\lambda_x} x) + B \sqrt{\lambda_x} \cos(\sqrt{\lambda_x} x) \] Evaluating this at \(x=0\) gives:

\[ \frac{dX}{dx}\Big|_{x=0} = B \sqrt{\lambda_x} = 0 \implies B = 0 \] Thus, the solution simplifies to: \[ X(x) = A \cos(\sqrt{\lambda_x} x) \] Now, applying the second boundary condition: \[ \frac{\partial u}{\partial x}\Big|_{x=L_x} = 0 \implies \frac{dX}{dx}\Big|_{x=L_x} = 0 \] Evaluating the derivative at \(x=L_x\) gives: \[ \frac{dX}{dx}\Big|_{x=L_x} = - A \sqrt{\lambda_x} \sin(\sqrt{\lambda_x} L_x) = 0 \] since \(A \neq 0\) and \(\sqrt{\lambda_x} \neq 0\), we have: \[ \sin(\sqrt{\lambda_x} L_x) = 0 \implies \sqrt{\lambda_x} L_x = n \pi \implies \lambda_x = \frac{n^2 \pi^2}{L_x^2} \quad n \in \mathbb{Z^{>0}} \]

If \(\lambda_x > 0\), then the solution to equation Equation 1.4 after applying the boundary conditions in Equation 4 is any eigenfunction of the form: \[ X_n(x) = A_n \cos\left(\sqrt{\lambda_x} x\right) \quad n \in \mathbb{Z^{>0}} \] where \(A_n\) are arbitrary constants associated with each eigenvalue \(\lambda_x = \frac{n^2 \pi^2}{L_x^2}\).

Zero-valued \(\lambda_x\)

NoteEvaluating the case of zero λx

When \(\lambda_x = 0\), we get repeated roots \(k_1 = k_2 = 0\), this means that the general solution to equation Equation 1.4 is not given by a linear combination of two independent exponential functions.

Instead, we can substitute \(\lambda_x = 0\) into equation Equation 1.4, we get \(\frac{d^2X}{dx^2} = 0\). This is a simple second-order ordinary differential equation, and its general solution is a linear function of \(x\):

\[ X(x) = A + B x \tag{1.10}\] where \(A\) and \(B\) are arbitrary constants that determine the specific solution depending on the boundary conditions. Applying the boundary conditions: \[ \frac{dX}{dx}\Big|_{x=0} = B = 0 \] and \[ \frac{dX}{dx}\Big|_{x=L_x} = B = 0 \]

The solution simplifies to: \[ X(x) = A \]

Negative \(\lambda_x\)

NoteEvaluating the case of negative λx

If \(\lambda_x < 0\), then \(k = \pm \sqrt{ |\lambda_x|}\). This means that the 2 independent solutions are:

\[ X_1(x) = e^{\sqrt{ |\lambda_x|} x} \] and \[ X_2(x) = e^{-\sqrt{ |\lambda_x|} x} \] which leads to the general solution: \[ X(x) = C_1 e^{\sqrt{ |\lambda_x|} x} + C_2 e^{-\sqrt{ |\lambda_x|} x} \]

\[ X(x) = A \cosh(\sqrt{|\lambda_x|} x) + B \sinh(\sqrt{|\lambda_x|} x) \tag{1.11}\]

The derivative of Equation 1.11 is: \[ \frac{dX}{dx} = A \sqrt{|\lambda_x|} \sinh(\sqrt{|\lambda_x|} x) + B \sqrt{|\lambda_x|} \cosh(\sqrt{|\lambda_x|} x) \]

Applying the first boundary condition:

\[ \frac{dX}{dx}\Big|_{x=0} = B \sqrt{|\lambda_x|} = 0 \implies B = 0 \]

Thus, the solution simplifies to:

\[ X(x) = A \cosh(\sqrt{|\lambda_x|} x) \]

and applying the second boundary condition:

\[ \frac{dX}{dx}\Big|_{x=L_x} = A \sqrt{|\lambda_x|} \sinh(\sqrt{|\lambda_x|} L_x) = 0 \]

Since \(A \neq 0\) and \(\sqrt{|\lambda_x|} \neq 0\), we have:

\[ \sinh(\sqrt{|\lambda_x|} L_x) = 0 \implies \sqrt{|\lambda_x|} L_x = 0 \implies \lambda_x = 0 \] This contradicts our initial assumption that \(\lambda_x < 0\).

Therefore, there are no solutions for \(\lambda_x < 0\).

This leads us to conclude that the only possible values for \(\lambda_x\) compatible with the boundary conditions in Equation 4 are \[ \lambda_x = \frac{n^2 \pi^2}{L_x^2} \quad n \in \mathbb{Z}^{\geq 0}, \] where \(\mathbb{Z}^{\geq 0}\) denotes the set of non‑negative integers. In particular, the case \(n = 0\) corresponds to the eigenvalue \(\lambda_x = 0\).

Thus, the general solution to equation Equation 1.4 that satisfies the boundary conditions in Equation 4 is:

\[ X_n(x) = A_n \cos\left(\frac{n \pi}{L_x} x\right), \quad n \in \mathbb{Z}^{\geq 0}. \]

Similarly, the solution to equation Equation 1.5 that satisfies the boundary conditions in Equation 4 is:

\[ Y_m(y) = B_m \cos\left(\frac{m \pi}{L_y} y\right), \quad m \in \mathbb{Z}^{\geq 0}. \]

Eigenfunctions

The space-dependent part of the solution Equation 1.1 is given by the products \(X_n(x) Y_m(y)\), which can be written as: \[ \Phi_{n,m}(x,y) = A_nB_m \cos\left(\frac{n \pi}{L_x} x\right)\cos\left(\frac{m \pi}{L_y} y\right), \quad n,m \in \mathbb{Z}^{\geq 0}, \] which are eigenfunctions of the Laplacian with Neumann boundary conditions, with eigenvalues \[ \lambda_{n,m} = \lambda_x + \lambda_y = \frac{n^2 \pi^2}{L_x^2} + \frac{m^2 \pi^2}{L_y^2}. \]

NoteThe product between \(X_n(x)\) and \(Y_m(y)\) also satisfies the eigenvalue equation

Eigenvalue equation verification

We can show that the eigenfunctions \(\Phi_{n,m}(x,y)\) associated with the eigenvalues \(\lambda_{n,m}\) satisfy the following eigenvalue equation for the Laplacian with Neumann boundary conditions: \[ \nabla^2 \Phi_{n,m}(x,y) = -\lambda_{n,m} \Phi_{n,m}(x,y) \tag{2.1}\] Here is the verification:

We found the eigenfunctions \(X_n(x)\) and \(Y_m(y)\) that satisfy the equations: \[ \frac{d^2X_n}{dx^2} = -\lambda_x X_n \quad \text{and} \quad \frac{d^2Y_m}{dy^2} = -\lambda_y Y_m, \tag{2.2}\]

And then we defined the eigenfunction \(\Phi_{n,m}(x,y)\) as the product of \(X_n(x)\) and \(Y_m(y)\). This means that the Laplacian of \(\Phi_{n,m}(x,y)\) can be computed as follows:

\[ \nabla^2 \Phi_{n,m}(x,y) = \frac{d^2}{dx^2} (X_n(x) Y_m(y)) + \frac{d^2}{dy^2} (X_n(x) Y_m(y)) \] \[ = Y_m(y) \frac{d^2X_n}{dx^2} + X_n(x) \frac{d^2Y_m}{dy^2} \] Now, substituting Equation 2.2 into the above equation, we get:

\[ \nabla^2 \Phi_{n,m}(x,y) = Y_m(y) (-\lambda_x X_n) + X_n(x) (-\lambda_y Y_m) \] \[ = -\lambda_x X_n(x) Y_m(y) - \lambda_y X_n(x) Y_m(y) \] \[ = -(\lambda_x + \lambda_y) \Phi_{n,m}(x,y) \] \[ = -\lambda_{n,m} \Phi_{n,m}(x,y) \]

Which is exactly the eigenvalue equation Equation 2.1 that we wanted to verify.

Infinite sum of eigenmodes

Substituting these results back into the temporal equation Equation 1.3, we find that a separated solution of the form \[ u_{n,m}(x,y,t) = X_n(x) Y_m(y) T_{n,m}(t) \] satisfies the diffusion equation Equation 1 with Neumann boundary conditions, where each separated solution (or eigenmode) associated with the pair \((n,m)\) can be written as \[ u_{n,m}(x,y,t) = \Phi_{n,m}(x,y)\, e^{-D \lambda_{n,m} t} = A_n B_m \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) e^{-D \lambda_{n,m} t}, \] where the overall multiplicative factor \(A_n B_m\) can again be absorbed into a single mode amplitude.

Because the set \(\{\Phi_{n,m}\}_{n,m \ge 0}\) forms an orthogonal basis of \(L^2([0,L_x]\times[0,L_y])\) adapted to the Neumann boundary conditions, any sufficiently regular initial condition can be expanded uniquely as a series in these spatial eigenfunctions. By linearity and superposition, the general solution to the diffusion equation Equation 1 takes the form \[ u(x,y,t) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m}\, \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) e^{-D \lambda_{n,m} t}, \tag{2.3}\]

and the coefficients \(C_{n,m}\) are determined by projecting the initial condition Equation 2 onto the spatial eigenfunctions \(\Phi_{n,m}\).

Determining the constants \(C_{n,m}\)

To find the constants \(C_{n,m}\), we can use the initial condition Equation 3. Evaluating the initial condition at \(t=0\) gives:

\[ u(x,y,0) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m} \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \tag{2.4}\]

We just need to find a way to calculate the coefficients \(C_{n,m}\). To do this, we will use the orthogonality property of the cosines to transform the infinite series problem into a integral calculation.

NoteOrthogonality of cosine functions

For any fixed \(L > 0\), the cosine functions \(\{\cos(\frac{n \pi x}{L})\}_{n=0}^{\infty}\) form an orthogonal basis on the interval \([0,L]\) with respect to the inner product. This means that if we have two different functions from this set, say \(\phi_n(x)\) and \(\phi_m(x)\): \[ \phi_{n}(x) = \cos\left(\frac{n \pi x}{L}\right) \quad n \in \mathbb{Z}^{\geq 0} \]

\[ \phi_{m}(x) = \cos\left(\frac{m \pi x}{L}\right) \quad m \in \mathbb{Z}^{\geq 0} \]

then the integral of their product is zero if \(n \neq m\). Mathematically, this orthogonality condition can be expressed as: \[ \int_0^L \phi_{n}(x) \phi_{m}(x) \, dx = \begin{cases} \frac{L}{2} & \text{if } n=m \text{ and } n,m > 0 \\ L & \text{if } n=m=0 \\ 0 & \text{if } n \neq m \end{cases} \tag{2.5}\]

Let’s define a new set of eigenfunctions:

\[ \phi_{p,q}(x,y) = \cos\left(\frac{p \pi}{L_x} x\right) \cos\left(\frac{q \pi}{L_y} y\right) \quad p,q \in \mathbb{Z}^{\geq 0} \]

Now, we multiply both sides of equation Equation 2.4 by \(\phi_{p,q}(x,y)\) to get:

\[ u(x,y,0) \phi_{p,q}(x,y) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m} \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \cos\left(\frac{p \pi}{L_x} x\right) \cos\left(\frac{q \pi}{L_y} y\right) \tag{2.6}\]

Next, we integrate both sides of equation Equation 2.6 over the domain \(\Omega\):

\[ \int_0^{L_x} \int_0^{L_y} u(x,y,0) \phi_{p,q}(x,y) \, dy \, dx = \] \[ =\sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m} \int_0^{L_x} \int_0^{L_y} \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right)\cos\left(\frac{p \pi}{L_x} x\right) \cos\left(\frac{q \pi}{L_y} y\right) \, dy \, dx \tag{2.7}\]

Rearranging the right-hand side of equation Equation 2.7 gives:

\[ =\sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m}\underbrace{ \left( \int_0^{L_x} \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{p \pi}{L_x} x\right) \, dx \right)}_{I_{x}(n,p)} \underbrace{\left( \int_0^{L_y} \cos\left(\frac{m \pi}{L_y} y\right) \cos\left(\frac{q \pi}{L_y} y\right) \, dy \right)}_{I_{y}(m,q)} \tag{2.8}\]

Here is where the orthogonality property shown in equation Equation 2.5 comes into play. The integrals \(I_{x}(n,p)\) and \(I_{y}(m,q)\) will have the following values:

\[ I_{x}(n,p) = \begin{cases} \frac{L_x}{2} & \text{if } n=p \text{ and } n,p > 0 \\ L_x & \text{if } n=p=0 \\ 0 & \text{if } n \neq p \end{cases} \] \[ I_{y}(m,q) = \begin{cases} \frac{L_y}{2} & \text{if } m=q \text{ and } m,q > 0 \\ L_y & \text{if } m=q=0 \\ 0 & \text{if } m \neq q \end{cases} \]

This means that all the terms in the infinite sums in equation Equation 2.8 will be zero except for the single term where \(n=p\) and \(m=q\).

\[ \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m} I_{x}(n,p) I_{y}(m,q) = C_{p,q} I_{x}(p,p) I_{y}(q,q) \tag{2.9}\]

Then, we can rewrite equation Equation 2.7 as:

\[ \int_0^{L_x} \int_0^{L_y} u(x,y,0) \phi_{p,q}(x,y) \, dy \, dx = C_{p,q} N_{x}(p) N_{y}(q) \tag{2.10}\]

where

\[ N_{x}(p) = \begin{cases} \frac{L_x}{2} & \text{if } p > 0 \\ L_x & \text{if } p=0 \end{cases} \qquad \text{and} \qquad N_{y}(q) = \begin{cases} \frac{L_y}{2} & \text{if } q > 0 \\ L_y & \text{if } q=0 \end{cases} \]

Finally, we can solve for the coefficients \(C_{p,q}\):

\[ C_{p,q} = \frac{1}{N_{x}(p) N_{y}(q)} \int_0^{L_x} \int_0^{L_y} u(x,y,0) \phi_{p,q}(x,y) \, dy \, dx \tag{2.11}\]

But wait, we were looking for \(C_{n,m}\), not \(C_{p,q}\). However, since the only term that survived in the infinite sums was the one where \(n=p\) and \(m=q\), we can simply substitute \(p\) by \(n\) and \(q\) by \(m\), leading to the final expression for the coefficients \(C_{n,m}\):

\[ C_{n,m} = \frac{1}{N_{x}(n) N_{y}(m)} \int_0^{L_x} \int_0^{L_y} u(x,y,0) \phi_{n,m}(x,y) \, dy \, dx \]

which is the same as:

\[ C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \int_0^{L_x} \int_0^{L_y} u(x,y,0) \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \, dy \, dx \tag{2.12}\]

where

\[ \varepsilon_{q} = \begin{cases} \frac{1}{2} & \text{if } q=0 \\ 1 & \text{if } q > 0 \end{cases} \]

Integrating with the initial condition

Now we can substitute the initial condition Equation 2 into equation Equation 2.12 to calculate the coefficients \(C_{n,m}\):

\[ C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \int_0^{L_x} \int_0^{L_y} \left( \sum_{i=1}^N S_i \delta(x-x_i) \delta(y-y_i) \right) \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \, dy \, dx \] Since the integral of the sum is equal to the sum of the integrals, we can rewrite this as:

\[C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \sum_{i=1}^N S_i \int_0^{L_x} \int_0^{L_y} \delta(x-x_i) \delta(y-y_i) \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) \, dy \, dx \] Since the domain is rectangular and we can separate the integrals, we have:

\[ C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \sum_{i=1}^N S_i \left( \int_0^{L_x} \delta(x-x_i) \cos\left(\frac{n \pi}{L_x} x\right) \, dx \right) \left( \int_0^{L_y} \delta(y-y_i) \cos\left(\frac{m \pi}{L_y} y\right) \, dy \right) \]

Here we can use the sifting property of the Dirac delta function, which states that for any function \(f(x)\):

\[ \int_{-\infty}^{\infty} f(x) \delta(x-a) \, dx = f(a) \]

which tells us that the integral of a function multiplied by a Dirac delta function is just the value of the function at the point where the delta function is centered. Applying this property to the integrals in the expression for \(C_{n,m}\) gives:

\[ C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \sum_{i=1}^N S_i \cos\left(\frac{n \pi}{L_x} x_i\right) \cos\left(\frac{m \pi}{L_y} y_i\right) \tag{2.13}\]

Final solution

Finally, substituting equation Equation 2.13 into equation Equation 2.3 gives the final solution to the equation Equation 1 with initial condition Equation 2 and boundary conditions Equation 4:

\[u(x,y,t) = \sum_{n=0}^{\infty} \sum_{m=0}^{\infty} C_{n,m} \cos\left(\frac{n \pi}{L_x} x\right) \cos\left(\frac{m \pi}{L_y} y\right) e^{-D \lambda_{n,m} t} \tag{3.1}\]

where

\[ C_{n,m} = \frac{4 \varepsilon_{n} \varepsilon_{m}}{L_x L_y} \sum_{i=1}^N S_i \cos\left(\frac{n \pi}{L_x} x_i\right) \cos\left(\frac{m \pi}{L_y} y_i\right) \] and

\[ \lambda_{n,m} = \frac{n^2 \pi^2}{L_x^2} + \frac{m^2 \pi^2}{L_y^2} \]

Since we cannot compute infinite sums numerically, we will approximate the solution by truncating the sums to a finite number of terms \(n_{max}\) and \(m_{max}\)

\[ \frac{\partial w}{\partial t} = D \nabla^2 w - \beta w \tag{3.2}\]

Confirming the solution for the constant decay rate case

We can confirm this solution by showing that we can arrive at equation Equation 1 from equation Equation 3.2 if the following relationship between their corresponding solutions \(u(x,y,t)\) and \(w(x,y,t)\) holds:

\[ w(x,y,t) = u(x,y,t) e^{-\beta t} \] Let’s find the first time derivative of \(w\) and the Laplacian of \(w\): \[ \frac{\partial w}{\partial t} = \frac{\partial u}{\partial t} e^{-\beta t} - \beta u e^{-\beta t} \]

\[ \nabla^2 w = \left( \frac{\partial^2 w}{\partial x^2} + \frac{\partial^2 w}{\partial y^2} \right) = \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right) e^{-\beta t} = \nabla^2 u e^{-\beta t} \]

Substituting these two expressions into equation Equation 3.2 gives:

\[ \frac{\partial u}{\partial t} e^{-\beta t} - \beta u e^{-\beta t} = D \nabla^2 u e^{-\beta t} - \beta u e^{-\beta t} \]

Then, we can divide both sides by \(e^{-\beta t}\) (which is never zero) to obtain:

\[ \frac{\partial u}{\partial t} - \beta u = D \nabla^2 u - \beta u \]

and then, by adding \(\beta u\) to both sides, we arrive at the original diffusion equation:

\[ \frac{\partial u}{\partial t} = D \nabla^2 u \]

This confirms that our proposed solution is correct.
