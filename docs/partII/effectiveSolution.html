Effective solution

As previusly reported (van Gestel, J., Bareia, T., Tenennbaum, B. et al. 2021), in the case of a system with a large number of point sources and sinks, and when the decay length \(\lambda\) is small compared to the system size, the concentration field can be approximated by an effective solution that takes into account the contributions of all sources and sinks in a weighted manner.

\[ f_{b}=\frac{S_b}{S_b+R_b} \] Where

\[ S_b = \sum_{k \in i} e^{-\frac{d_{bk}}{\lambda}} \] \[ R_b = \sum_{l \in j} e^{-\frac{d_{bl}}{\lambda}} \]

We can imagine that the bacteria are densly packed and this density is homogeneously distributed in the domain \(\Omega = [0,L_x]\times[0,L_y]\)

This way, the denominator can be aproximated by

\[ F(x,y)=\int_0^{L_x} \int_0^{L_y} e^{-\sqrt{(x-x_i)²+(y-y_i)²}/\lambda} dy_i dx_i \]

This looks like this:

Nx_0=50
Ny_0=50
xs_0 = Array.from({length: Nx_0}, (_, i) => i/(Nx_0-1)*LxNew);
ys_0 = Array.from({length: Ny_0}, (_, j) => j/(Ny_0-1)*LyNew);


function F(x,y){
  let sum = 0
  let dx = LxNew/(Nx_0-1)
  let dy = LyNew/(Ny_0-1)
  for (let i=0; i<Nx_0; i++){
    for (let j=0; j<Ny_0; j++){
      let x_i = xs_0[i]
      let y_i = ys_0[j]
      let dist = Math.sqrt((x - x_i)**2 + (y - y_i)**2)
      sum += Math.exp(-dist/lambdaNew)*dx*dy
    }
  }
  return sum
}

Z = ys_0.map(y => xs_0.map(x => F(x,y)))

Let’s add now \(N\) producer bacteria as point sources

\[ Q(x,y)=\sum_{k}^N \delta(x-x_k,y-y_k) \]

And compute the value for the numerator

\[ G(x,y)=\int_0^{L_x} \int_0^{L_y} \sum_{k}^N \delta(x_i-x_k,y_i-y_k) e^{-\sqrt{(x-x_i)²+(y-y_i)²}/\lambda} dy_i dx_i \]

\[ G(x,y)=\sum_{k}^N \int_0^{L_x} \int_0^{L_y} \delta(x_i-x_k,y_i-y_k) e^{-\sqrt{(x-x_i)²+(y-y_i)²}/\lambda} dy_i dx_i \] and using the sifting property of the delta function we get \[ G(x,y)=\sum_{k}^N e^{-\sqrt{(x-x_k)²+(y-y_k)²}/\lambda} \]

  let sum = 0

Now, if we combine both results into the effective solution we get:

\[ f_{b}(x,y)=\frac{G(x,y)}{F(x,y)} \]
