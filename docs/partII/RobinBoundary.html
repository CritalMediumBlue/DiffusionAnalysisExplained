3  Mixed boundary conditions

Let’s consider the same non-homogeneous diffusion equation described in Chapter 1

\[ \frac{\partial v}{\partial t} = D \nabla^2 v + Q(x,y,t) - \beta v \tag{3.1}\]

where \[ Q(x,y,t) = \sum_{i=1}^N A_i \delta(x-x_i) \delta(y-y_i) \] represents point-like sources located at positions \((x_i,y_i)\), with production rates \(A_i\). This time, we will impose mixed boundary conditions on one edge of the domain. This is with the goal of modeling the microfluidic device as a rectangular domain which has 3 impermeable walls (Neumann boundary conditions) and one edge that connects the chamber to an external reservoir, allowing for diffusion across the domain (Robin boundary condition).

For reflective (Neumann) boundaries: \[ \frac{\partial v}{\partial x}\Big|_{x=0} = \frac{\partial v}{\partial x}\Big|_{x=L_x} = \frac{\partial v}{\partial y}\Big|_{y=0} = 0 \] For the Robin boundary at \(y=L_y\):

\[ -D \frac{\partial v}{\partial y}\Big|_{y=L_y} =J= k (v(x,L_y,t) - v_{ext}) \]

\(J\) is the diffusion flux across the Robin boundary in the outward normal direction, and it is proportional to the concentration difference between the interior part of the domain at \(y=L_y\) and an external reservoir with concentration \(v_{ext}\), \(D\) is the diffusion coefficient, \(k\) is the mass transfer coefficient. For simplicity, we will assume that \(v_{ext}\) is zero.

Let’s solve this equation using 2 different methods: Eigenfunction expansion and Green’s functions.

But first, we need to find the eigenfunctions that satisfy the mixed boundary conditions.

3.1 Finding eigenfunctions with mixed boundary conditions

To find the eigenfunctions, we start with the spatial eigenvalue problem associated with the homogeneous part of the diffusion equation:

\[ \frac{\partial v}{\partial t} = D \nabla^2 v - \beta v \tag{3.2}\] We assume that the solution can be separated into spatial and temporal parts:

\[ v(x,y,t) = X(x) Y(y) T(t) \]

Substituting this into Equation 3.2 gives:

\[ XY \frac{dT}{dt} = D T \left( Y \frac{d^2X}{dx^2} + X \frac{d^2Y}{dy^2} \right) - \beta XYT \] Dividing both sides by \(XYTD\) leads to:

\[ \frac{1}{D T} \frac{dT}{dt} = \frac{1}{X} \frac{d^2X}{dx^2} + \frac{1}{Y} \frac{d^2Y}{dy^2} - \frac{\beta}{D} \] reorganizing terms, we have: \[ \frac{1}{D T} \frac{dT}{dt} + \frac{\beta}{D} = \frac{1}{X} \frac{d^2X}{dx^2} + \frac{1}{Y} \frac{d^2Y}{dy^2} \]

since the left side depends only on time and the right side only on space, both sides must equal a constant, which we denote as \(-\lambda\). This gives us two separate equations:

\[ \frac{1}{D T} \frac{dT}{dt} + \frac{\beta}{D} = -\lambda \] \[ \frac{1}{X} \frac{d^2X}{dx^2} + \frac{1}{Y} \frac{d^2Y}{dy^2} = -\lambda \] This gives us 3 ordinary differential equations:

\[\frac{dT}{dt} = -(\lambda + \frac{\beta}{D}) DT \tag{3.3}\] \[\frac{d^2X}{dx^2} = -\lambda_x X \tag{3.4}\] \[\frac{d^2Y}{dy^2} = -\lambda_y Y \tag{3.5}\] with the constraint that \(\lambda = \lambda_x + \lambda_y\).

The solution to Equation 3.3 is:

\[ T(t) = T(0) e^{-(\lambda + \frac{\beta}{D}) Dt} \]

Next, we need to solve Equation 3.4 and Equation 3.5. As shown in Section 1.2.1, the general solutions are:

\[ X(x) = A_x \cos(\sqrt{\lambda_x} x) + B_x \sin(\sqrt{\lambda_x} x) \] \[ Y(y) = A_y \cos(\sqrt{\lambda_y} y) + B_y \sin(\sqrt{\lambda_y} y) \]

Let’s apply the boundary conditions to find the constants and the allowed values of \(\lambda_x\) and \(\lambda_y\).

For the Neumann boundary conditions at \(x=0\) and \(x=L_x\): \[ \frac{dXYT}{dx}\Big|_{x=0} = YT \frac{dX}{dx}\Big|_{x=0} = 0 \] \(Y\) and \(T\) can not be zero for all \(y\) and \(t\), so we have: \[ \frac{dX}{dx}\Big|_{x=0} = 0 \implies B_x = 0 \] Next, we apply the Neumann boundary condition at \(x=L_x\): \[ \frac{dX}{dx}\Big|_{x=L_x} = 0 \implies -A_x \sqrt{\lambda_x} \sin(\sqrt{\lambda_x} L_x) = 0 \] This leads to the allowed values of \(\lambda_x\): \[\sqrt{\lambda_x} L_x = n \pi \implies \lambda_x = \left(\frac{n \pi}{L_x}\right)^2, \quad n \in \mathbb{Z}^{\geq 0}\]

Thus, the eigenfunctions in the \(x\) direction are: \[\boxed{ X_n(x) = A_n \cos\left(\frac{n \pi x}{L_x}\right)}\]

Now, let’s apply the reflective boundary condition at \(y=0\): \[ \frac{dY}{dy}\Big|_{y=0} = 0 \implies B_y = 0 \]

Next, we apply the Robin boundary condition at \(y=L_y\):

\[ -D \frac{d YXT}{dy}\Big|_{y=L_y} = k (Y(L_y)XT - v_{ext}) \]

We will assume \(v_{ext}=0\). Dividing both sides by \(XT\), we get:

\[ -D \frac{dY}{dy}\Big|_{y=L_y} = k (Y(L_y)) \] Substituting the expression for \(Y(y)\), we have: \[ -D \left(-A_y \sqrt{\lambda_y} \sin(\sqrt{\lambda_y} L_y)\right) = k \left(A_y \cos(\sqrt{\lambda_y} L_y)\right) \] Rearranging terms, we obtain the following equation: \[ \tan(\sqrt{\lambda_y} L_y) = \frac{k}{D \sqrt{\lambda_y}} \]

Let’s plot the left and right sides of this equation to find the allowed values of \(\lambda_y\).

Code 
Plotly = require("plotly.js-dist@2")

k = 10
D = 1
Ly = 1

x = Array.from({length: 2000}, (_, i) => (i + 1) * 0.005) // avoid xi=0

// Tune these:
YMAX = 10          // don’t draw tan outside [-YMAX, YMAX]
COS_EPS = 1e-3     // don’t draw near asymptotes where cos≈0
pointsX = [1.43, 4.315, 7.25]
pointsY = pointsX.map(xi => k / (D * xi))
y1 = x.map(xi => {
  const u = xi * Ly
  const c = Math.cos(u)
  if (Math.abs(c) < COS_EPS) return null     // break line near asymptotes
  const t = Math.tan(u)
  if (!Number.isFinite(t)) return null
  if (Math.abs(t) > YMAX) return null        // optional: also clip large values
  return t
})

y2 = x.map(xi => k / (D * xi)) // this has a singularity at 0; x starts > 0

plot = {
  const div = document.createElement("div")
  div.style.height = "400px"
  div.style.width = "600px"

  Plotly.newPlot(div, [
    {x, y: y1, type: "scatter", mode: "lines", name: "tan(√λy * Ly)"},
    {x, y: y2, type: "scatter", mode: "lines", name: "k / (D * √λy)"},
    {
      x: pointsX,
      y: pointsY,
      type: "scatter",
      mode: "markers",
      name: "solutions",
      marker: {color: "red", size: 8}
    }
  ], {
    title: "Finding Eigenvalues λy",
    xaxis: {title: "√λy"},
    yaxis: {title: "Value", range: [-1, 10]},
    width: 600,
    height: 400,
    margin: {l: 20, r: 0, b: 30, t: 30}
  })

  return div
}
